# go-ai-coder

🚀 Enterprise-grade AI coding assistant with local AI processing, GitHub integration and web scraping capabilities. Built with Go and powered by Ollama.

## Overview
Part of the [bakery-street-project](https://github.com/bakery-street-project) enterprise ecosystem.

## Tech Stack
- **Primary Language**: Go
- **CI/CD**: GitHub Actions

## Getting Started
```bash
git clone https://github.com/bakery-street-project/go-ai-coder.git
cd go-ai-coder
```
